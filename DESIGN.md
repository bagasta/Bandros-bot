# Persistent Agent Workspace design direction

Owner direction: workspace kerja yang tenang dan mudah untuk orang awam.

Reading this as: productivity workspace for first-time agent users, in a calm editorial style, dial ENERGY 1 / RHYTHM 2 / MOTION 1.

- Palette: muted teal for orientation and one terracotta accent for the primary action.
- Typography: Plus Jakarta Sans for friendly, highly legible labels and explanations.
- Layout: a clear work queue with one focal action, generous grouping, and plain-language state labels.
- Motion: only short feedback transitions; reduced-motion users see the final state immediately.

Decision reasons: teal separates navigation from content without urgency; terracotta reserves attention for creating work; asymmetric content grouping makes the next action obvious; no decorative illustration is used because the real workspace state is the product evidence.
